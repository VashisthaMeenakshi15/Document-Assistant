# ⚡ Local Document RAG Assistant

A free, private, multi-format RAG application built with Streamlit, LangChain, ChromaDB, and Groq API.

## 🚀 Features
- **Multi-Format Parsing:** PPTX, PDF, DOCX, HTML, XLSX, CSV.
- **Fast Vector Retrieval:** ChromaDB in-memory embeddings.
- **Ultra-Fast LLM:** Powered by Groq API (Llama 3.3 70B / Qwen 2.5).
- **Custom UI:** Modern light theme with right-aligned user bubbles and citation badges.
